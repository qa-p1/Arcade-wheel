# Arcade Wheel

Arcade Wheel is a radial launcher for desktop actions. Hold its trigger, move toward an action, then release to run it. Switch decks while holding, or assign center gestures to launch a routine.

## What Wheel is best at

- **Launching with one movement.** Put applications, commands, files, folders and links into slots around the wheel.
- **Grouping work.** Create decks for different tasks and switch between them while the wheel is open.
- **Running a short routine.** Assign single-click, double-click, triple-click or long-press gestures in the center hub.
